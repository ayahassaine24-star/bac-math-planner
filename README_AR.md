# خطة البكالوريا — شعبة الرياضيات (الإصدار 2)

تطوير للمشروع الأصلي `bac_math_pwa` مع الاحتفاظ بملف `index.html` وبنية PWA البسيطة، ونقل الملاحظات والجدول الأسبوعي القديم إلى الإصدار الجديد عند أول تشغيل متى كانت بيانات النسخة القديمة موجودة في المتصفح نفسه.

## المحتويات
- `index.html`: التطبيق كاملًا، بواجهات عربية RTL متجاوبة.
- `manifest.webmanifest`: تعريف PWA وإعدادات التثبيت.
- `sw.js`: تخزين ملفات التطبيق للعمل دون اتصال بعد الزيارة الأولى عبر HTTPS/localhost.
- `icon.svg`, `icon-192.png`, `icon-512.png`: أيقونات التطبيق.

## التشغيل من الهاتف (Android)
1. ارفعي **محتويات مجلد `bac_math_pwa`** إلى مستودع GitHub، لا ملف ZIP نفسه.
2. من المستودع افتحي **Settings → Pages**، واختاري النشر من الفرع `main` والمجلد `/ (root)`.
3. بعد اكتمال النشر، افتحي الرابط الفعلي الذي يعرضه GitHub Pages في Chrome. يجب أن يكون HTTPS.
4. افتحي قائمة Chrome ⋮ واختاري **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**. يظهر زر التثبيت داخل التطبيق فقط عندما يبلّغ Chrome أن شروط التثبيت متحققة.
5. افتحي التطبيق مرة وهو متصل بالإنترنت حتى تُخزّن الملفات اللازمة، وبعد ذلك يمكن فتح الواجهة الأساسية دون اتصال.

يمكن الاختبار محليًا عبر خادم تطوير يدعم HTTPS أو `localhost`؛ فتح `index.html` مباشرة من مدير الملفات لا يفعّل Service Worker ولا يثبت PWA. لا يتطلب المشروع حسابًا مدفوعًا أو خادمًا لتشغيل وظائفه المحلية.

## الميزات
- الرئيسية: تاريخ اليوم، المهام المستحقة، التقدم واختصارات.
- جدول أسبوعي قابل للإضافة والتعديل والحذف، بعرض يوم أو أسبوع، وأوقات بداية ونهاية قابلة للتحرير.
- مؤقت تركيز مخصص للتركيز والاستراحة القصيرة والطويلة. يعتمد على وقت نهاية مطلق بدل عدّ الثواني بشكل تراكمي، ولا يسجل جلسة التركيز إلا عند اكتمالها.
- مهام بأولوية وموعد نهائي، ودروس مع حالات التقدم.
- إحصائيات للجلسات والساعات والمهام والدروس حسب المادة.
- وضع فاتح/داكن، لون تمييز، وتصدير/استيراد JSON مع فحص بنية النسخة وحجمها.
- تخزين محلي في `localStorage`، ولا يقوم عامل الخدمة بحذف بيانات التطبيق عند تحديث ملفات الواجهة.

## البيانات والخصوصية
البيانات محفوظة في المتصفح على الجهاز نفسه، وليست متزامنة تلقائيًا مع أجهزة أخرى. صدّري نسخة JSON دوريًا، خصوصًا قبل مسح بيانات Chrome أو تغيير الجهاز. الاستيراد يستبدل البيانات الحالية بعد التأكيد؛ احتفظي بنسخة قبل الاستيراد.

## حدود معروفة
- المتصفحات قد تؤخر JavaScript والتنبيهات أثناء إطفاء الشاشة أو تقييد التطبيق في الخلفية؛ عند العودة يُعاد حساب الوقت من الطابع الزمني، لكن لا يمكن ضمان تنبيه دقيق في كل أجهزة Android.
- التخزين المحلي قد يُمسح إذا مسحتِ بيانات المتصفح أو أزلتِ بيانات التطبيق. النسخ الاحتياطية هي وسيلة النقل بين الأجهزة.
- تم إجراء فحص بناء JavaScript وفحص ملفات المشروع الأساسية، لكن لم يتم تشغيل اختبار آلي كامل داخل Chrome Android أو اختبار انقطاع اتصال حقيقي في هذه البيئة. اختبري التثبيت والعمل دون اتصال على رابط HTTPS بعد النشر.
