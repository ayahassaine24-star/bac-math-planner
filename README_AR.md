# مشروع خطة البكالوريا — شعبة الرياضيات

## ما الذي يتضمنه؟
- جدول أسبوعي للمراجعة المنزلية حول مواقيت الثانوية التي زودتِني بها.
- متابعة الحصص ونسبة الإنجاز وتقدم المواد.
- صفحة لمواقيت الثانوية وملاحظات شخصية.
- حفظ التقدم والملاحظات في المتصفح على الهاتف.
- ملف Manifest وعامل خدمة لتثبيته كتطبيق ويب تقدمي (PWA).

## قبل النشر
وقت السبت في صفحة مواقيت الثانوية تقريبي لأن الفترة الصباحية/المسائية لم تُحدد بالتفصيل. عدّليه في `index.html` إذا لزم. كما أن حصص المراجعة المنزلية اقتراح أولي ويمكن تعديلها مباشرة في مصفوفة `sessions` داخل `index.html`.

## النشر مجانًا عبر GitHub Pages
1. سجّلي الدخول إلى GitHub وأنشئي مستودعًا جديدًا (Repository) باسم `bac-math-planner`.
2. اجعليه **Public** لتفعيل GitHub Pages مجانًا، ثم أنشئي المستودع.
3. ارفعي ملفات المشروع الخمسة إلى جذر المستودع: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `README_AR.md`.
4. افتحي **Settings → Pages**.
5. في **Build and deployment** اختاري **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغطي **Save**.
6. انتظري اكتمال النشر. سيظهر رابط الموقع في صفحة Pages، غالبًا بصيغة:
   `https://اسم-المستخدم.github.io/bac-math-planner/`
   لا تكتبي هذا الرابط تخمينًا؛ استخدمي الرابط الذي يعرضه GitHub فعلًا.

## التثبيت على Android
1. افتحي رابط الموقع المنشور في Google Chrome على الهاتف.
2. افتحي قائمة النقاط الثلاث ⋮.
3. اختاري **Install app / تثبيت التطبيق** أو **Add to Home screen / إضافة إلى الشاشة الرئيسية** (قد تختلف التسمية).
4. أكّدي التثبيت. ستظهر أيقونة «خطة البكالوريا» على الشاشة الرئيسية.

## ملاحظات مهمة
- لا أستطيع نشر الموقع داخل حساب GitHub الخاص بك من دون أن تسجّلي الدخول وتنفذي خطوات الرفع.
- يجب أن يكون الموقع منشورًا عبر HTTPS حتى يظهر خيار التثبيت بصورة صحيحة.
- الحصص المنجزة والملاحظات محفوظة محليًا في المتصفح/التطبيق على هذا الجهاز؛ لا توجد مزامنة تلقائية بين أجهزة مختلفة.
- عامل الخدمة يخزّن ملفات التطبيق لتساعده على الفتح عند انقطاع الإنترنت بعد أول زيارة ناجحة، لكن هذا ليس شرطًا لاستخدامه اليومي.
